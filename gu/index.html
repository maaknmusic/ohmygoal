રેન્ડમ વીડિયો ચેટ, ગુજરાતીમાં

એક બટન દબાવો અને નવી વ્યક્તિ સાથે સામસામે વાત કરો. OhMyGoal મફત છે, એકાઉન્ટની જરૂર નથી, ઉંમરની ચકાસણી તમારા પોતાના ફોન પર થાય છે અને કોઈ ચેટ રેકોર્ડ થતી નથી.

ચેટ શરૂ કરો →મફત · સાઇન-અપ નહીં · 18+

  • વીડિયો, વોઇસ કે ટેક્સ્ટચહેરો બતાવો, ફક્ત અવાજ, કે ફક્ત લખો.
  • રેકોર્ડિંગ નહીંવીડિયો સીધો બંનેના બ્રાઉઝર વચ્ચે જાય છે.
  • નગ્નતા ઝાંખીતમારા ફોન પર જ તપાસીને અશ્લીલ વીડિયો ઝાંખો કરાય છે.
  • UPI છેતરપિંડીની ચેતવણીકોઈ ફોન નંબર કે UPI ID મોકલે તો ચેતવણી.

કેવી રીતે શરૂ કરવું

  1. વીડિયો, વોઇસ કે ટેક્સ્ટ પસંદ કરો. ઇચ્છો તો રસ (ક્રિકેટ, સંગીત, અભ્યાસ…) ઉમેરો.
  2. પહેલી ચેટ પહેલાં કેમેરા તમારા ફોન પર જ ઉંમરનો અંદાજ લગાવે છે. કોઈ ફોટો અપલોડ થતો નથી.
  3. Start દબાવો અને વાત કરો. બીજું કોઈ જોઈએ તો Next દબાવો.

સુરક્ષિત રહો

  • કેમેરા સામે ક્યારેય કપડાં ન ઉતારો. સામેની વ્યક્તિ સ્ક્રીન રેકોર્ડ કરી શકે છે.
  • વીડિયોના નામે કોઈ બ્લેકમેલ કરે તો પૈસા ન આપો. 1930 પર કૉલ કરો અથવા cybercrime.gov.in પર ફરિયાદ કરો.
  • દરેક ચેટમાં Report અને Block છે. નિયમ તોડનારા પર ડિવાઇસ, નેટવર્ક અને એકાઉન્ટ ત્રણેય પર પ્રતિબંધ.

પ્રશ્નો

શું આ ખરેખર મફત છે?

હા. વીડિયો, વોઇસ અને ટેક્સ્ટ ચેટ, ગેમ્સ અને બધી સુરક્ષા સુવિધાઓ મફત છે, એકાઉન્ટ જરૂરી નથી. Premium (₹49 થી) ફક્ત વધારાની સુવિધાઓ માટે.

શું મારી ચેટ રેકોર્ડ થાય છે?

ના. વીડિયો અને મેસેજ અમે સાચવતા નથી. છતાં સામેની વ્યક્તિ પોતાની સ્ક્રીન રેકોર્ડ કરી શકે છે, તેથી સાવચેત રહો.

શું ફોન પર ચાલે છે?

હા, Android અને iPhone પર કોઈપણ આધુનિક બ્રાઉઝરમાં. એપ ડાઉનલોડ કરવાની જરૂર નથી.
